# Checklist Windows - chưa thực hiện

Các file `.bat` đã kèm theo, chưa chạy trên Windows trong môi trường này.
Dùng JDK 17+ / Ant; giải nén vào đường dẫn có dấu cách để thử quoting.
Kiểm tra build, driver, config/biến môi trường, bootstrap trong terminal tương tác,
backend TLS và client, cả ba role, login đổi mật khẩu, đăng xuất/thoát,
back/forward/nháp, thử DPI 100/125/150%, 1366x768 và 1920x1080, đổi kích thước cửa sổ.
Thử nhập tiếng Việt, bàn phím/trợ năng, máy quét, máy in, CSV tiếng Việt và số 0 đầu.
Mất mạng/restart phải giữ pending request để đối soát, không ghi trùng.
Lưu ảnh/log riêng có ngày, OS, JDK, database DEMO/Test và hash bản chạy.
